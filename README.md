# ניהול רכב (CarCare)

תוכנה לניהול טיפולים, תיקונים והוצאות לרכב (Windows).

המאגר הזה משמש **שרת עדכונים**: כל גרסה חדשה מתפרסמת כאן תחת Releases,
והתוכנה בודקת בכל פתיחה אם יש גרסה חדשה, מורידה ומתקינה אותה. הנתונים במחשב לא משתנים.

התקנה: מורידים את הקובץ CarCare-X.Y.Z.zip מהגרסה האחרונה ב-Releases, פותחים את ה-zip
ומעתיקים את התיקייה "ניהול רכב" לכונן שאינו C (למשל D:\CarCare), ואז מפעילים את CarCare.exe.
